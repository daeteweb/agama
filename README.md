### 經文分類
* **雜阿含經(Saṁyukta Āgama)**：原名「相應阿含」，是禪修者的實修指南和了義的「第一義悉檀」。東晉時求那跋陀羅譯出，因其內容短小、分類結集而得名，共50卷。全經超過1300篇短文，內容精簡，主要對應南傳巴利藏的《相應部》。詳述四聖諦、八正道、五蘊、十二因緣等核心教義，被認為是最接近佛陀原始教法的經典，為修禪者必修。
  
* **中阿含經(Madhyama Āgama)**：篇幅中等，被視為學問者的深入教科書，屬破斥邪見的「對治悉檀」。東晉僧伽提婆譯，全經結構完整，是漢譯四阿含中唯一保存完整目錄（攝頌） 的經典，共60卷。它深入抉擇法義，系統闡述各種修行法門的細微差別，包含222經，主要對應南傳巴利藏的《中部》。
  
* **長阿含經(Dīrgha Āgama)**：因收錄篇幅較長的經文而得名，主要用於破斥外道邪見，屬「各各為人悉檀」。後秦佛陀耶舍譯，分為四分四誦，共22卷。內容包含佛陀本生與宇宙觀以及辯破外道思想的記錄（僅30經），主要對應南傳巴利藏的《長部》。
  
* **增一阿含經(Ekottarikāgama)**：成立最晚，以法數（1法、2法…）為綱編排，被視為勸化者的教材，屬隨順凡情、廣結善緣的「世界悉檀」。東晉僧伽提婆譯，現存51卷本。內容包含豐富的佛陀與弟子事蹟、在家修行規範及簡明定義佛教的著名偈頌（含472經），主要對應南傳巴利藏的《增支部》。
