# 雜阿含經 第 178 經

### [原文]
如是我聞：

一時，佛住舍衛國祇樹給孤獨園。

爾時，世尊告諸比丘：「猶如有人火燒頭衣，當云何救？」

比丘白佛言：「世尊！起增上欲，慇懃方便時救令滅。」

佛告比丘：「頭衣燒然尚可暫忘，無常盛火應盡斷。為斷無常火故，已生惡不善法當斷，起欲、精勤、攝心令增長。斷何等無常法故，已生惡不善法為斷故，起欲、方便、攝心增進？謂色無常故，受、想、行、識無常當斷故，已生惡不善法令斷，起欲、方便、攝心增進……」廣說乃至……。

佛說此經已，諸比丘聞佛所說，歡喜奉行。

如無常經，如是過去無常、未來無常、現在無常、過去未來無常、過去現在無常、未來現在無常、過去未來現在無常八經，亦如上說。

如已生惡不善法當斷故，如是未生惡不善法令不生、未生善法令生、已生善法令增廣故，起欲、方便、攝心增進八經，亦如上說。

如當斷無常三十二經，如是當知、當吐、當盡、當止、當捨、當滅、當沒一一三十二經，廣說如上。

### [白話翻譯]
**◈ 如是我聞：**
　　我是這樣聽佛陀說的：

**◈ 一時，佛住舍衛國祇樹給孤獨園。**
　　在某一個時間，佛陀住在舍衛國的祇樹給孤獨園中。

**◈ 爾時，世尊告諸比丘：「猶如有人火燒頭衣，當云何救？」**
　　那時，世尊告訴在場的眾位比丘說：「就好像有一個人的頭巾被火燒著了，應該如何救他？」

**◈ 比丘白佛言：「世尊！起增上欲，慇懃方便時救令滅。」**
　　比丘對佛陀恭敬地說道：「世尊！應該生起強烈的願望，並以勤勉且巧妙的手段及時救援，使火熄滅。」

**◈ 佛告比丘：「頭衣燒然尚可暫忘，無常盛火應盡斷。」**
　　佛陀告訴比丘：「頭巾被燒著了，或許還能暫時忽略，但無常（Anicca）這場劇烈的烈火，則應該徹底斷除。」

**◈ 「為斷無常火故，已生惡不善法當斷，起欲、精勤、攝心令增長。」**
　　「為了斷除無常之火，對於心中已經產生的惡劣不善法應該予以斷除，並生起願望、精進努力以及收攝心念，使這些正向的特質增長。」

**◈ 「斷何等無常法故，已生惡不善法為斷故，起欲、方便、攝心增進？」**
　　「為什麼要斷除無常之法？為什麼要斷除已經產生的惡劣不善法，而要生起願望、運用方便手段並收攝心念來增進修行？」

**◈ 「謂色無常故，受、想、行、識無常當斷故，已生惡不善法令斷，起欲、方便、攝心增進……」廣說乃至……。**
　　「是因為色（物質身體）是無常的，受（感受）、想（想像與認知）、行（心的造作）、識（意識）也同樣是無常的，因此應該斷除對這些五蘊的執著。為了這個目的，應斷除已產生的惡劣不善法，並生起願望、運用方便手段且收攝心念來增進修行……」佛陀詳細地說明直到結束。

**◈ 佛說此經已，諸比丘聞佛所說，歡喜奉行。**
　　佛陀講完這部經後，眾比丘聽聞佛陀所說的教法，心生法喜並依照教導去實踐。

**◈ 如無常經，如是過去無常、未來無常、現在無常、過去未來無常、過去現在無常、未來現在無常、過去未來現在無常八經，亦如上說。**
　　就像這部《無常經》一樣，關於過去無常、未來無常、現在無常、過去與未來無常、過去與現在無常、未來與現在無常、以及過去未來現在三時無常的八部經，也同樣如上所述。

**◈ 如已生惡不善法當斷故，如是未生惡不善法令不生、未生善法令生、已生善法令增廣故，起欲、方便、攝心增進八經，亦如上說。**
　　就像針對「已產生的惡不善法應當斷除」的教導一樣，關於「尚未產生的惡不善法令其不生」、「尚未產生的善法令其產生」、「已產生的善法令其增廣」而生起願望、運用方便並收攝心念的八部經，也同樣如上所述。

**◈ 如當斷無常三十二經，如是當知、當吐、當盡、當止、當捨、當滅、當沒一一三十二經，廣說如上。**
　　就像關於「應斷除無常」的三十二部經一樣，關於「應當知曉」、「應當吐出（捨棄）」、「應當盡除」、「應當停止」、「應當捨離」、「應當滅盡」、「應當沒入（消融）」的各三十二部經，詳細說明皆如上述。

### [詞語註解]
1. **增上欲 (Adhiṭṭhāna/Chanda)**：指一種強烈的、正向的志向或願望，是推動修行者克服惰性、達成解脫目標的心理動力。
2. **方便 (Upāya)**：指為了達到特定目的而採取的巧妙、適當且有效的手段或方法。
3. **攝心 (Samādhi/Citta-saṃvara)**：指將散亂的心念收攏，專注於單一的對象或正念中，防止心隨外境而飄蕩。
4. **惡不善法 (Akusala-dhamma)**：指會導致痛苦、染污心靈且產生惡業的心理狀態，如貪、嗔、痴。
5. **五蘊 (Pañca-khandha)**：構成生命個體的五種要素，包含色（物質身體）、受（感受）、想（想像與認知）、行（心的造作）、識（意識）。

### [現代實作指南]
本經以「火燒頭衣」作為強烈的隱喻，旨在喚醒修行者對「無常」的緊迫感（Samvega）。在現代生活中，我們可以透過以下步驟實踐：

1. **建立緊迫感（覺察火在燒）**：
   ➔ 練習在日常生活中觀察「變遷」。例如：觀察一次憤怒的升起與消失，或觀察身體在一天之內疲累與恢復的過程。意識到所有感受（受）與認知（想）都在瞬間變換，如同頭上的火，如果不處理，最終會導致痛苦。

2. **生起增上欲（決定救火）**：
   ➔ 當意識到生活中的壓力或情緒（惡不善法）正在損害心靈時，不要採取逃避態度，而是生起一種「我必須現在就解決這個問題」的強烈願望。將這種願望轉化為對平靜與覺悟的追求。

3. **運用方便與攝心（採取救火行動）**：
   ➔ **攝心**：當情緒激動時，立即將注意力從外部衝突（外境）收回到呼吸上，切斷惡法增長的燃料。
   ➔ **方便**：根據當下情況選擇方法。若因壓力而焦慮，可使用「正念觀察」；若因貪婪而不安，可使用「觀照無常」來對治。

4. **針對五蘊的解構練習**：
   ➔ 當你對某件事感到強烈執著時，問自己：
     - 這是我的「色（身體）」在反應嗎？
     - 這是我的「受（感受）」在作祟嗎？
     - 這是我的「想（認知）」在定義它嗎？
     - 這是我的「行（造作）」在推動我反應嗎？
     - 這是我的「識（意識）」在分辨它嗎？
   ➔ 意識到這五者皆在變動且無常，執著便會自然減輕。

### [段落大意]
本段經文以「頭巾著火」比喻生命中無常的危險，強調面對無常之火應具有強烈的願望（增上欲）與正確的手段（方便、攝心）來斷除惡不善法。佛陀明確指出，色、受、想、行、識五蘊皆是無常的，因此必須斷除對其的執著。文末提及此教法延伸至過去、現在、未來三時無常，以及關於善法增長與惡法斷除的系列教導。
