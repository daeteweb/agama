# 雜阿含經 第 162 經

### [原文]
如是我聞：

一時，佛住舍衛國祇樹給孤獨園。

爾時，世尊告諸比丘：「何所有故，何所起？何所繫著，何所見我？令諸眾生作如是見、如是說：『作、教作，斷、教斷，煮、教煮，殺、教殺，害眾生、盜他財、行邪婬、知言妄語、飲酒、穿牆、斷鏁、偷奪，復道害村、害城、害人民，以極利劍輪鈆割，斫截作大肉聚，作如是學：「彼非惡因緣，亦非招惡。於恒水南殺害而去，恒水北作大會而來，彼非因緣福惡，亦非招福惡。惠施、調伏、護持、行利、同利，於此所作，亦非作福。」』？」

諸比丘白佛：「世尊是法根、法眼、法依……」如是廣說，次第如上三經。

### [白話翻譯]
**◈ 如是我聞：**
　　我是這樣聽佛陀說的：

**◈ 一時，佛住舍衛國祇樹給孤獨園。**
　　在某一個時間，佛陀住在舍衛國的祇樹給孤獨園。

**◈ 爾時，世尊告諸比丘：**
　　那時，世尊告訴在場的眾位比丘說：

**◈ 「何所有故，何所起？何所繫著，何所見我？**
　　「究竟是因為有什麼存在，才會導致現象興起？是什麼在束縛著眾生？又是什麼被誤認為了『我』（執著於一個恆常不變的自我）？

**◈ 令諸眾生作如是見、如是說：**
　　導致有情（擁有意識與生命的眾生）產生這樣的錯誤見解，並這樣宣稱：

**◈ 『作、教作，斷、教斷，煮、教煮，殺、教殺，害眾生、盜他財、行邪婬、知言妄語、飲酒、穿牆、斷鏁、偷奪，復道害村、害城、害人民，以極利劍輪鈆割，斫截作大肉聚，**
　　『無論是親自實行或教唆他人去實行：砍斷、教人砍斷，煮熟（生物）、教人煮熟，殺害、教人殺害，傷害有情（擁有意識與生命的眾生）、盜取他人財產、從事不正當的性行為、故意說謊、飲酒、破牆而入、斬斷鎖鏈、偷竊搶奪，甚至進一步毀壞村莊、毀壞城市、傷害人民，使用極其鋒利的劍或輪鈆（切割工具）來切割，將肢體砍斷並堆積成巨大的肉塊，

**◈ 作如是學：「彼非惡因緣，亦非招惡。**
　　並以此作為教導說：「這些行為並非惡的因緣（緣起/因果關係），也不會招致惡的業報（Vipāka）。

**◈ 於恒水南殺害而去，恒水北作大會而來，彼非因緣福惡，亦非招福惡。**
　　即便在恆河以南殺害眾生後離開，隨後在恆河以北參加盛大的集會回來，這些行為也不構成福或惡的因緣（緣起），更不會招致福或惡的業報（Vipāka）。

**◈ 惠施、調伏、護持、行利、同利，於此所作，亦非作福。」』？」**
　　而像是在行布施、調伏心靈、護持正法、利益他人、與他人共同獲利等善行，這些所作之舉，也不是在創造福報（業報）。』」

**◈ 諸比丘白佛：「世尊是法根、法眼、法依……」**
　　眾比丘對佛陀恭敬地說道：「世尊，您所說的這段教法是正法的根源、是洞察真理的法眼、是修行的依據……」

**◈ 如是廣說，次第如上三經。**
　　如此詳細地說明，其順序與上述三部經文相同。

### [詞語註解]
1. **因緣 (Paṭicca-samuppāda)**：指事物並非獨立存在，而是依據特定的條件（因與緣）而生起。在此指行為（因）與其結果（果）的必然聯繫。
2. **業報 (Vipāka)**：行為（Kamma）所產生的結果。惡行導致惡報，善行導致善報。
3. **有情 (Satta)**：指所有具有意識、能感受到痛苦與快樂，並在輪迴中流轉的生命體。
4. **法根/法眼/法依**：比丘對佛陀教法的讚嘆，指該教法提供了正確的基礎（根）、正確的觀察視角（眼）以及可靠的實踐準則（依）。

### [現代實作指南]
本段經文揭露了一種極其危險的「虛無主義」見解 ➔ 即認為行為與結果之間沒有關聯（無因果論）。在現代生活中，這種心態常表現為：「只要不被發現，做壞事就沒有代價」或「隨便對人好也沒有意義」。

**實踐轉念技巧：**
1. **覺察「因果斷裂感」**：當你產生「反正沒關係」、「這樣做也不會怎樣」的念頭時，立刻意識到這是在陷入「非因緣」的錯誤見解。
2. **建立「微小因果」觀察紀錄**：
   - **惡因觀察**：記錄一次對他人不耐煩（因） ➔ 觀察隨後產生的內心不安或對方冷漠的反應（果）。
   - **善因觀察**：記錄一次無私的幫助（因） ➔ 觀察隨後產生的內心寧靜或關係改善（果）。
3. **拒絕道德相對主義**：明白傷害他人（如經文所述的極端暴力）在意識深處會種下深刻的痛苦種子，無論地理位置（恆河南北）或形式（集會）如何改變，業力（Kamma）的運作不隨環境而消失。

---

### [段落大意]
佛陀詢問比丘關於錯誤見解的起源，特別是那些主張「行為不產生業報」的虛無主義觀點。這種觀點認為極端的暴力犯罪既不構成惡因也不招惡報，而善行亦不創造福報。比丘對此教法表示高度認同，認為這是正法的核心依據。
