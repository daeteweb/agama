# 雜阿含經 第 179 經

### [原文]
如是我聞：

一時，佛住舍衛國祇樹給孤獨園。

爾時，世尊告諸比丘：「猶如有人火燒頭衣，當云何救？」

比丘白佛言：「世尊！當起增上欲，慇懃方便時救令滅？」

佛告比丘：「頭衣燒燃尚可暫忘，無常盛火當盡斷。為斷無常火故，當修欲定斷行成就如意足。當斷何等法無常？謂當斷色無常，當斷受、想、行、識無常故，修欲定斷行成就如意足……」如經廣說，乃至……。

佛說此經已，諸比丘聞佛所說，歡喜奉行。

如無常，如是過去無常、未來無常、現在無常、過去未來無常、過去現在無常、未來現在無常、過去未來現在無常八經，亦如上說。

如修欲定，如是精進定、意定、思惟定亦如是。如當斷三十二經，如是當知、當吐、當盡、當止、當捨、當滅、當沒一一三十二經，亦如上說。

### [白話翻譯]
**◈ 如是我聞：**
　　我是這樣聽佛陀說的：

**◈ 一時，佛住舍衛國祇樹給孤獨園。**
　　在某一個時間，佛陀住在舍衛國的祇樹給孤獨園。

**◈ 爾時，世尊告諸比丘：「猶如有人火燒頭衣，當云何救？」**
　　那時，世尊告訴在場的眾位比丘說：「就像有一個人的頭巾被火燒著了，應該如何救他？」

**◈ 比丘白佛言：「世尊！當起增上欲，慇懃方便時救令滅？」**
　　比丘對佛陀恭敬地說道：「世尊！應該激發強烈的願望，迅速地採取適當的方法來救他，使火熄滅嗎？」

**◈ 佛告比丘：「頭衣燒燃尚可暫忘，無常盛火當盡斷。」**
　　佛陀告訴比丘：「頭巾被火燒著雖然可能暫時被忽略，但無常（一切現象不斷變遷）的劇烈之火則必須徹底斷除。」

**◈ 「為斷無常火故，當修欲定斷行成就如意足。」**
　　「為了斷除這場無常之火，應該修行欲定（以強烈願望而建立的專注力）與斷行（斷除煩惱的實踐），以成就如意足（隨心所欲的神通能力）。」

**◈ 「當斷何等法無常？謂當斷色無常，當斷受、想、行、識無常故，修欲定斷行成就如意足……」**
　　「應該斷除什麼樣的法（現象）之無常呢？也就是說，應該斷除色（物質身體）的無常，斷除受（感受）的無常、想（想像與認知）的無常、行（心的造作）的無常以及識（意識）的無常，因此要修行欲定與斷行，以成就如意足……」

**◈ 如經廣說，乃至……。**
　　經文中詳細地說明，直到……。

**◈ 佛說此經已，諸比丘聞佛所說，歡喜奉行。**
　　佛陀講完這部經後，眾比丘聽聞佛陀所說的教法，心生法喜並依照教導去實踐。

**◈ 如無常，如是過去無常、未來無常、現在無常、過去未來無常、過去現在無常、未來現在無常、過去未來現在無常八經，亦如上說。**
　　如同說明無常一樣，關於過去的無常、未來的無常、現在的無常、過去與未來的無常、過去與現在的無常、未來與現在的無常，以及過去、未來、現在三者的無常，這八種關於無常的教法，也同樣如上所述。

**◈ 如修欲定，如是精進定、意定、思惟定亦如是。**
　　如同修行欲定一樣，精進定（以努力而建立的專注）、意定（以心念而建立的專注）、思惟定（以思考而建立的專注）也是如此。

**◈ 如當斷三十二經，如是當知、當吐、當盡、當止、當捨、當滅、當沒一一三十二經，亦如上說。**
　　如同應當斷除的三十二種教法一樣，關於應當知、應當吐（排除）、應當盡、應當止、應當捨、應當滅、應當沒，這三十二種教法中的每一項，也同樣如上所述。

### [詞語註解]
1. **無常 (Anicca)**：指所有條件合成的現象（有為法）都處於不斷的變遷之中，沒有永恆不變的實體。
2. **欲定 (Chanda-samādhi)**：此處的「欲」非指世俗貪欲，而是指對解脫的強烈願望（Chanda），以此願望作為動力來建立專注的定力。
3. **如意足 (Iddhividha)**：一種精神上的成就，指修行者能隨心自在地運用心力，在佛教脈絡中常指對心靈掌控的極致能力。
4. **五蘊 (Pañca-khandha)**：構成生命個體的五種要素，包含色（物質）、受（感受）、想（認知）、行（造作）、識（意識）。
5. **斷行 (Vimocchana/Cutting action)**：透過智慧與實踐，切斷對無常現象的執著，從而止息苦因的行動。

### [現代實作指南]
本經文使用「火燒頭衣」的強烈意象，旨在提醒修行者面對「無常」時應具備的**緊迫感**。在現代生活中，我們可以將其轉化為以下實踐：

1. **建立「緊迫感」的覺知**：
   ➔ 當我們陷入對金錢、名聲或身體健康的執著時，試著將這些執著想像成「頭上的火」。意識到這些東西隨時會變遷（無常），而非永恆。這種緊迫感能將我們從懶散的狀態推向積極的修行。

2. **轉化「欲」為「願」**：
   ➔ 將對感官享受的「貪欲」轉化為對心靈自由的「強烈願望」（欲定）。例如：不再追求「如何獲得更多」，而轉向追求「如何不再被失去所困擾」。

3. **五蘊的拆解觀察**：
   ➔ 當強烈的情緒（受）或固執的看法（想）產生時，立即提醒自己：「這是受的無常」、「這是想的無常」。透過將整體的身心拆解為五蘊來觀察，能有效降低對「我」的執著，使心靈在變動中保持穩定。

4. **從「知」到「斷」的行動**：
   ➔ 不要僅止於理論上知道「人生無常」，而要採取「斷行」。當發現自己正在對某件無常之事產生過度依戀時，立即練習「捨」的動作，在心中對該執著說：「這是不恆久的，我不應將其視為永恆的依託」。

### [段落大意]
佛陀以火燒頭巾比喻無常的危險與緊迫，強調應以強烈的解脫願望（欲定）與實踐（斷行）來斷除對五蘊無常的執著。文中進一步將此邏輯擴展至時間維度的八種無常、不同類型的定力，以及三十二種斷除之法，旨在指導修行者徹底根除對變遷現象的依戀。
