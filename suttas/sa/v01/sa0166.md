# 雜阿含經 第 166 經

### [原文]
如是我聞：

一時，佛住舍衛國祇樹給孤獨園。

爾時，世尊告諸比丘：「何所有故，何所起？何所繫著，何所見我？令諸眾生作如是見、如是說：『色是我，餘則虛名；無色是我，餘則虛名；色非色是我，餘則虛名；非色非無色是我，餘則虛名；我有邊，餘則虛名；我無邊，餘則虛名；我有邊無邊，餘則虛名；我非有邊非無邊，餘則虛名。一想、種種想、多想、無量想，我一向樂、一向苦、若苦、樂、不苦不樂，餘則虛名。』？」

諸比丘白佛言：「世尊是法根、法眼、法依……」廣說次第如上三經。

### [白話翻譯]
**◈ 如是我聞：**
　　我是這樣聽佛陀說的：

**◈ 一時，佛住舍衛國祇樹給孤獨園。**
　　在某一個時間，佛陀住在舍衛國的祇樹給孤獨園。

**◈ 爾時，世尊告諸比丘：**
　　那時，世尊告訴在場的眾位比丘說：

**◈ 「何所有故，何所起？何所繫著，何所見我？**
　　「為什麼會有所執著？是什麼引起了這種狀態？是什麼將人繫縛？又是基於什麼而產生了對『我』的錯誤見解？

**◈ 令諸眾生作如是見、如是說：**
　　導致眾生產生這樣的見解並這樣說道：

**◈ 『色是我，餘則虛名；**
　　『色（物質身體）就是我，而其餘的受（感受）、想（想像與認知）、行（心的造作）、識（意識）都只是虛名；

**◈ 無色是我，餘則虛名；**
　　非物質的要素是我，而其餘的都只是虛名；

**◈ 色非色是我，餘則虛名；**
　　既是物質又非物質的東西是我，而其餘的都只是虛名；

**◈ 非色非無色是我，餘則虛名；**
　　既非物質也非非物質的東西是我，而其餘的都只是虛名；

**◈ 我有邊，餘則虛名；**
　　我有邊界（有限），而其餘的都只是虛名；

**◈ 我無邊，餘則虛名；**
　　我沒有邊界（無限），而其餘的都只是虛名；

**◈ 我有邊無邊，餘則虛名；**
　　我既有邊界又無邊界，而其餘的都只是虛名；

**◈ 我非有邊非無邊，餘則虛名。**
　　我既非有邊界也非無邊界，而其餘的都只是虛名。』

**◈ 一想、種種想、多想、無量想，**
　　（眾生）產生一種想（想像與認知）、種種的想、許多想或無量無邊的想，

**◈ 我一向樂、一向苦、若苦、樂、不苦不樂，餘則虛名。』？」**
　　認為我一直處於快樂中、一直處於痛苦中，或者處於痛苦、快樂、或是不苦不樂的狀態，而其餘的都只是虛名。」

**◈ 諸比丘白佛言：「世尊是法根、法眼、法依……」**
　　眾比丘對佛陀恭敬地說道：「世尊，這是法（真理）的根源、法（真理）的洞察力、法（真理）的依據……」

**◈ 廣說次第如上三經。**
　　接下來詳細說明次第的內容與前三部經相同。

### [詞語註解]
1. **色 (Rūpa)**：指一切物質現象，在五蘊中特指物質身體。
2. **虛名**：指缺乏實體、僅僅是語言標記的名稱，用以對比被誤認為「真實自我」的部分。
3. **有邊/無邊 (Limited/Unlimited)**：古印度哲學中關於「我（Atman）」之空間屬性的爭論，討論靈魂是有限的還是無限的。
4. **想 (Saññā)**：心靈對對象的辨識、標記與認知功能。
5. **法根/法眼/法依**：比丘對佛陀的讚嘆，指佛陀是真理的源頭、能洞察真理的智慧之眼，以及修行者可以依止的真理準則。

### [現代實作指南]
本段經文揭示了人類最深層的認知陷阱：**「認同感」的錯位**。我們習慣將某個部分（如身體、某種情緒、或某種信念）定義為「我」，而將其餘部分視為附屬品或虛名。

**實作步驟：**
1. **覺察認同的切換** ➔ 當你感到痛苦時，觀察心念是否在說「我很痛苦」？此時你將「受（感受）」認同為「我」。
2. **解構「我」的邊界** ➔ 試著問自己：「如果我的身體（色）在改變，我的想法（想）在變換，那麼那個不變的『我』在哪裡？」
3. **標記「虛名」** ➔ 當你對自己的身份產生強烈執著（例如：我是個成功的人、我是個失敗的人）時，提醒自己這僅僅是一個「虛名」，是心靈造作（行）出的標籤，而非永恆的實體。
4. **練習「非此非彼」** ➔ 不要陷入「我是物質」或「我是精神」的二元對立，而是觀察這五種要素（五蘊）如何因緣而生、因緣而滅，無需將其中任何一項定義為恆常的自我。

### [段落大意]
佛陀詢問比丘，眾生為何會產生對「我」的執著，導致他們將自我認同於物質身體、非物質要素，或對自我的邊界與感受產生種種極端且矛盾的見解（如認為我僅是身體，或我處於永恆的苦樂中）。比丘隨後對佛陀的智慧表示崇敬，確認佛陀是真理的依據。
