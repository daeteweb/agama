# 雜阿含經 第 131 經

### [原文]
如是我聞：

一時，佛住舍衛國祇樹給孤獨園。

爾時，世尊告諸比丘：「若沙門、婆羅門習於色者，隨魔自在，入於魔手，隨魔所欲，為魔所縛，不脫魔繫。受、想、行、識亦復如是。若沙門、婆羅門不習色。如是沙門、婆羅門不隨魔自在，不入魔手，不隨魔所欲，解脫魔縛，解脫魔繫。」

佛說是經已，諸比丘聞佛所說，歡喜奉行。

如是，習近者、習著者、味者、決定著者、止者、使者、往者、撰擇者、不捨者、不吐者，如是等沙門、婆羅門隨魔自在，如上說。

### [白話翻譯]
**◈ 如是我聞：**
　　我是這樣聽佛陀說的：

**◈ 一時，佛住舍衛國祇樹給孤獨園。**
　　在某一個時間，佛陀住在舍衛國的祇樹給孤獨園。

**◈ 爾時，世尊告諸比丘：**
　　那時，世尊告訴在場的眾位比丘說：

**◈ 「若沙門、婆羅門習於色者，隨魔自在，入於魔手，隨魔所欲，為魔所縛，不脫魔繫。**
　　「如果沙門（修行者）或婆羅門（祭司階級）習慣於執著色（物質身體）的人，就會任由魔羅（象徵煩惱與誘惑）掌控，陷入魔羅的手中，隨其意願而動，被魔羅束縛，無法從這種束縛中解脫。

**◈ 受、想、行、識亦復如是。**
　　對於受（感受）、想（想像與認知）、行（心的造作）、識（意識）的執著也是同樣的情況。

**◈ 若沙門、婆羅門不習色。**
　　如果沙門或婆羅門不習慣於執著色（物質身體）。

**◈ 如是沙門、婆羅門不隨魔自在，不入魔手，不隨魔所欲，解脫魔縛，解脫魔繫。」**
　　這樣的沙門或婆羅門就不會任由魔羅掌控，不會陷入魔羅的手中，不會隨其意願而動，能從魔羅的束縛中解脫，從魔羅的繫縛中解脫。」

**◈ 佛說是經已，諸比丘聞佛所說，歡喜奉行。**
　　佛陀講完這部經後，眾比丘聽聞佛陀所說的教法，心生法喜並依照教導去實踐。

**◈ 如是，習近者、習著者、味者、決定著者、止者、使者、往者、撰擇者、不捨者、不吐者，如是等沙門、婆羅門隨魔自在，如上說。**
　　同樣地，那些親近執著的人、習慣依附的人、對其產生眷戀的人、決定執著的人、停留其中的人、被其驅使的人、趨向其中的人、刻意選擇的人、不願捨棄的人、不願吐棄的人，這些沙門或婆羅門都會任由魔羅掌控，情況就如上述所說。

### [詞語註解]
1. **色 (Rūpa)**：指物質身體及所有物質現象。
2. **受 (Vedanā)**：指對刺激產生的苦、樂、捨三種感受。
3. **想 (Saññā)**：指對對象的辨識、標記與認知。
4. **行 (Saṅkhāra)**：指心靈的造作、意志或心理傾向。
5. **識 (Viññāṇa)**：指對對象的覺知或意識。
6. **魔 (Māra)**：在原始佛教中，魔羅不僅指神話人物，更代表阻礙修行、導致輪迴的貪欲、嗔恚、痴心等煩惱。

### [現代實作指南]
本經文揭示了「習慣（習）」與「束縛」之間的因果關係。在現代生活中，我們可以將其轉化為以下心理實踐：

1. **識別「習慣性執著」**：
   觀察自己對物質（色）或情緒（受）的反應。例如，當你習慣於透過購買奢侈品（色）或追求讚美（受）來獲得滿足時，這就是一種「習」。意識到這種習慣，就是解脫的開始。

2. **覺察「魔的掌控」**：
   當你發現自己無法停止刷手機、無法控制對某人的執著，或被憤怒驅使時，請將此狀態標記為「隨魔自在」。這能幫助你將「自我」與「衝動」分離，從而產生觀察者的視角。

3. **練習「不習」的轉念**：
   當強烈的慾望或感受升起時，不要試圖強行壓抑，而是採取「不習」的態度 ➔ 觀察它，但不與之認同，不讓它變成一種習慣性的反應模式。

4. **斷除「眷戀」的環節**：
   經文末尾提到的「味者」、「不捨者」是指對感官快感的沉溺。實作時可嘗試「短暫禁欲」或「簡約生活」，透過刻意地不選擇（不撰擇）來削弱心靈對特定對象的依賴。

### [段落大意]
本段經文強調，若修行者習慣於執著五蘊（色、受、想、行、識），將會被煩惱（魔）所掌控與束縛；反之，若能不執著於五蘊，則能獲得真正的解脫。文中詳細列舉了各種執著的心理狀態，警示親近與眷戀感官對象將導致被魔羅束縛。
