# 雜阿含經 第 108 經

### [原文]
如是我聞：

一時，佛住釋氏天現聚落。

爾時，有西方眾多比丘欲還西方安居，詣世尊所，稽首佛足，退坐一面。

爾時，世尊為其說法，示、教、照、喜。種種示、教、照、喜已，時西方眾多比丘從座起，合掌白佛言：「世尊！我西方眾多比丘欲還西方安居，今請奉辭。」

佛告西方諸比丘：「汝辭舍利弗未？」

答言：「未辭。」

佛告西方諸比丘：「舍利弗淳修梵行，汝當奉辭，能令汝等以義饒益，長夜安樂。」

時，西方諸比丘辭退欲去。時，尊者舍利弗去佛不遠，坐一堅固樹下，西方諸比丘往詣尊者舍利弗所，稽首禮足，退坐一面，白尊者舍利弗言：「我等欲還西方安居，故來奉辭。」

舍利弗言：「汝等辭世尊未？」

答言：「已辭。」

舍利弗言：「汝等還西方，處處異國，種種異眾，必當問汝。汝等今於世尊所，聞善說法，當善受、善持、善觀、善入，足能為彼具足宣說，不毀佛耶？不令彼眾難問、詰責、墮負處耶？」

彼諸比丘白舍利弗：「我等為聞法故，來詣尊者，唯願尊者具為我說，哀愍故！」

尊者舍利弗告諸比丘：「閻浮提人聰明利根，若剎利、若婆羅門、若長者、若沙門，必當問汝：『汝彼大師云何說法？以何教教汝？』當答言：『大師唯說調伏欲貪，以此教教。』

「當復問汝：『於何法中調伏欲貪？』當復答言：『大師唯說於彼色陰調伏欲貪，於受、想、行、識陰調伏欲貪，我大師如是說法。』

「彼當復問：『欲貪有何過患故，大師說於色調伏欲貪？受、想、行、識調伏欲貪？』汝復應答言：『若於色欲不斷、貪不斷、愛不斷、念不斷、渴不斷者，彼色若變、若異，則生憂、悲、惱、苦。受、想、行、識亦復如是。見欲貪有如是過故，於色調伏欲貪，於受、想、行、識調伏欲貪。』

「彼復當問：『見斷欲貪，有何福利故，大師說於色調伏欲貪，於受、想、行、識調伏欲貪？』當復答言：『若於色斷欲、斷貪、斷念、斷愛、斷渴，彼色若變、若異，不起憂、悲、惱、苦。受、想、行、識亦復如是。』

「諸尊！若受諸不善法因緣故，今得現法樂住，不苦、不礙、不惱、不熱，身壞命終生於善處者，世尊終不說言：『當斷諸不善法。亦不教人於佛法中修諸梵行，得盡苦邊。以受諸不善法因緣故，今現法苦住，障礙熱惱，身壞命終，墮惡道中。』是故世尊說言：『當斷不善法，於佛法中修諸梵行，平等盡苦，究竟苦邊。』

「若受諸善法因緣，現法苦住，障礙熱惱，身壞命終墮惡道中者，世尊終不說受持善法，於佛法中，修諸梵行，平等盡苦，究竟苦邊。受持善法，現法樂住，不苦、不礙、不惱、不熱，身壞命終，生於善處，是故世尊讚歎、教人受諸善法，於佛法中，修諸梵行，平等盡苦，究竟苦邊。」

尊者舍利弗說是法時，西方諸比丘不起諸漏，心得解脫。尊者舍利弗說是法時，諸比丘歡喜隨喜，作禮而去。

### [白話翻譯]
**◈ 如是我聞：**
　　我是這樣聽佛陀說的：

**◈ 一時，佛住釋氏天現聚落。**
　　在某一個時間，佛陀住在釋迦族的天現聚落。

**◈ 爾時，有西方眾多比丘欲還西方安居，詣世尊所，稽首佛足，退坐一面。**
　　那時，有許多來自西方的比丘（出家僧侶）想要回到西方進行安居（雨季修行），於是前往世尊（佛陀）那裡，向佛陀的足下頂禮，然後退到一邊坐下。

**◈ 爾時，世尊為其說法，示、教、照、喜。種種示、教、照、喜已，時西方眾多比丘從座起，合掌白佛言：「世尊！我西方眾多比丘欲還西方安居，今請奉辭。」**
　　那時，世尊為他們宣說法（真理），給予指引、教導、啟發與鼓勵。在進行了各種指引、教導、啟發與鼓勵之後，這些西方比丘從座位上站起來，雙手合十對佛陀恭敬地說道：「世尊！我們這些西方比丘想要回到西方進行安居，現在請求向您告辭。」

**◈ 佛告西方諸比丘：「汝辭舍利弗未？」**
　　佛陀告訴這些西方比丘：「你們向舍利弗告辭了嗎？」

**◈ 答言：「未辭。」**
　　比丘們回答：「還沒有告辭。」

**◈ 佛告西方諸比丘：「舍利弗淳修梵行，汝當奉辭，能令汝等以義饒益，長夜安樂。」**
　　佛陀告訴西方比丘：「舍利弗純淨地修行梵行（清淨的修行生活），你們應該去向他告辭，他能讓你們在法義上獲得利益，在漫長的生死輪迴之夜中獲得安樂。」

**◈ 時，西方諸比丘辭退欲去。時，尊者舍利弗去佛不遠，坐一堅固樹下，西方諸比丘往詣尊者舍利弗所，稽首禮足，退坐一面，白尊者舍利弗言：「我等欲還西方安居，故來奉辭。」**
　　於是，西方比丘們告辭準備離開。那時，舍利弗尊者在距離佛陀不遠的地方，坐在一棵堅固的樹下。西方比丘們前往舍利弗尊者那裡，向其足下頂禮，退到一邊坐下，對舍利弗尊者說：「我們想要回到西方進行安居，所以特地來向您告辭。」

**◈ 舍利弗言：「汝等辭世尊未？」**
　　舍利弗問：「你們向世尊告辭了嗎？」

**◈ 答言：「已辭。」**
　　比丘們回答：「已經告辭了。」

**◈ 舍利弗言：「汝等還西方，處處異國，種種異眾，必當問汝。汝等今於世尊所，聞善說法，當善受、善持、善觀、善入，足能為彼具足宣說，不毀佛耶？不令彼眾難問、詰責、墮負處耶？」**
　　舍利弗說：「你們回到西方後，會經過不同的國家，遇到各種不同的人，他們一定會詢問你們。你們現在在世尊那裡聽聞了善巧的法（真理），應當好好地接受、好好地持守、好好地觀察、好好地進入（實踐），這樣才能為那些人完整地宣說，而不會損害佛陀的名聲，也不會讓那些眾生提出刁難的問題、詰責或找出漏洞，對吧？」

**◈ 彼諸比丘白舍利弗：「我等為聞法故，來詣尊者，唯願尊者具為我說，哀愍故！」**
　　那些比丘對舍利弗說：「我們正是為了聽法而來拜訪尊者，唯願尊者出於慈悲，為我們詳細地解說！」

**◈ 尊者舍利弗告諸比丘：「閻浮提人聰明利根，若剎利、若婆羅門、若長者、若沙門，必當問汝：『汝彼大師云何說法？以何教教汝？』當答言：『大師唯說調伏欲貪，以此教教。』**
　　舍利弗尊者告訴比丘們：「閻浮提（人類居住的世界）的人聰明且根基銳利，無論是剎利階級、婆羅門、長者或是沙門，一定會問你們：『你們的那位大師是如何說法的？用什麼教導來教導你們？』你們應當回答：『大師僅僅教導如何調伏（制止）對欲樂的貪愛，以此來教導我們。』」

**◈ 「當復問汝：『於何法中調伏欲貪？』當復答言：『大師唯說於彼色陰調伏欲貪，於受、想、行、識陰調伏欲貪，我大師如是說法。』**
　　「他們會再問你們：『在什麼法（現象/對象）之中調伏欲貪？』你們應當回答：『大師教導在色（物質身體）這一蘊（堆積）中調伏欲貪，在受（感受）、想（想像與認知）、行（心的造作）、識（意識）這四個蘊中調伏欲貪，我的大師就是這樣說法的。』」

**◈ 「彼當復問：『欲貪有何過患故，大師說於色調伏欲貪？受、想、行、識調伏欲貪？』汝復應答言：『若於色欲不斷、貪不斷、愛不斷、念不斷、渴不斷者，彼色若變、若異，則生憂、悲、惱、苦。受、想、行、識亦復如是。見欲貪有如是過故，於色調伏欲貪，於受、想、行、識調伏欲貪。』**
　　「他們會再問：『欲貪有什麼過患（危險），大師才說要在色（物質身體）以及受、想、行、識（感受、認知、造作、意識）中調伏欲貪？』你們應當回答：『如果對於色（物質身體）的欲望不斷、貪愛不斷、愛著不斷、執念不斷、渴求不斷的話，當那個物質身體發生改變或變得不同時，就會產生憂慮、悲傷、煩惱與痛苦。受、想、行、識這四個蘊也是同樣的道理。正因為看到欲貪有這樣的過患，所以才要在色、受、想、行、識中調伏欲貪。』」

**◈ 「彼復當問：『見斷欲貪，有何福利故，大師說於色調伏欲貪，於受、想、行、識調伏欲貪？』當復答言：『若於色斷欲、斷貪、斷念、斷愛、斷渴，彼色若變、若異，不起憂、悲、惱、苦。受、想、行、識亦復如是。』**
　　「他們會再問：『看見斷除欲貪有什麼福利（好處），大師才說要在色、受、想、行、識中調伏欲貪？』你們應當回答：『如果在色（物質身體）上斷除了欲望、貪愛、執念、愛著與渴求，即使那個物質身體發生改變或變得不同，也不會產生憂慮、悲傷、煩惱與痛苦。受、想、行、識這四個蘊也是同樣的道理。』」

**◈ 「諸尊！若受諸不善法因緣故，今得現法樂住，不苦、不礙、不惱、不熱，身壞命終生於善處者，世尊終不說言：『當斷諸不善法。亦不教人於佛法中修諸梵行，得盡苦邊。以受諸不善法因緣故，今現法苦住，障礙熱惱，身壞命終，墮惡道中。』是故世尊說言：『當斷不善法，於佛法中修諸梵行，平等盡苦，究竟苦邊。』**
　　「各位！如果承受不善法（惡因）的因緣（條件），現在能讓人在現世快樂地生活，沒有痛苦、障礙、煩惱與熱惱，且身體毀壞、生命結束後能生在好的地方，那麼世尊絕對不會說：『應該斷除所有不善法』，也不會教人於佛法中修行梵行（清淨生活）以結束痛苦。然而，正因為承受不善法的因緣，會導致現在現世生活痛苦、充滿障礙與熱惱，且死後墮入惡道，所以世尊才說：『應該斷除不善法，在佛法中修行梵行，平等地結束所有痛苦，達到痛苦的終結。』」

**◈ 「若受諸善法因緣，現法苦住，障礙熱惱，身壞命終墮惡道中者，世尊終不說受持善法，於佛法中，修諸梵行，平等盡苦，究竟苦邊。受持善法，現法樂住，不苦、不礙、不惱、不熱，身壞命終，生於善處，是故世尊讚歎、教人受諸善法，於佛法中，修諸梵行，平等盡苦，究竟苦邊。」**
　　「同樣地，如果受持善法的因緣，卻導致現世痛苦、充滿障礙與熱惱，且死後墮入惡道，世尊絕對不會教人受持善法或修行梵行。正因為受持善法能讓人在現世快樂地生活，沒有痛苦、障礙、煩惱與熱惱，且死後生在善處，所以世尊才讚歎並教人受持善法，在佛法中修行梵行，平等地結束所有痛苦，達到痛苦的終結。」

**◈ 尊者舍利弗說是法時，西方諸比丘不起諸漏，心得解脫。尊者舍利弗說是法時，諸比丘歡喜隨喜，作禮而去。**
　　舍利弗尊者在說這段法時，西方比丘們不再產生諸漏（煩惱的滲漏），心靈獲得了解脫。在舍利弗尊者說法時，比丘們感到歡喜並隨喜，向尊者行禮後才離開。

### [詞語註解]
1. **安居 (Vassa)**：比丘在雨季期間停止遊行，留在固定地點修行三個月的制度。
2. **梵行 (Brahmacariya)**：指清淨的修行生活，包含戒律的遵守與對解脫的追求。
3. **五蘊 (Pañca-kkhandha)**：構成身心的五種要素，包括色（物質身體）、受（感受）、想（想像與認知）、行（心的造作）、識（意識）。
4. **因緣 (Paṭicca-samuppāda)**：指事物並非單一原因產生，而是由「因」（直接原因）與「緣」（間接條件）共同促成。
5. **漏 (Āsava)**：指滲漏出的煩惱，通常指欲愛漏、有漏與無明漏，是導致輪迴的根本原因。
6. **現法樂住**：指在目前的生命階段（現世）中獲得快樂與安適。

### [現代實作指南]
本經文提供了一個極其精準的「痛苦診斷模型」，可用於現代生活中的壓力與情緒管理：

1. **識別「欲貪」的對象**：
   當我們感到憂慮或痛苦時，試著分析我們正對哪個「蘊」產生執著：
   - **色（物質）**：對外貌衰老、財產損失、身體疾病的恐懼 ➔ 意識到物質身體必然變異。
   - **受（感受）**：渴望快感永恆，或厭惡痛苦持續 ➔ 意識到感受是流動且無常的。
   - **想（認知）**：執著於某種對事物的看法或定義 ➔ 意識到認知僅是心智的標籤。
   - **行（造作）**：執著於自己的意志必須被實現 ➔ 意識到心的造作受因緣驅動。
   - **識（意識）**：執著於一個恆定的「我」在感知 ➔ 意識到意識僅是連續的閃現。

2. **邏輯轉念法**：
   - **痛苦公式**：`執著（欲貪） + 變異（無常） = 憂悲惱苦`。
   - **解脫公式**：`斷除執著 + 接受變異 = 不起憂悲惱苦`。
   - **實作**：當你對某件失去的事物感到悲傷時，告訴自己：「我現在的痛苦並非來自於『失去』，而是來自於我對那個『色/受/想/行/識』的欲貪（不願其改變）。」

3. **因果責任制**：
   - 意識到目前的處境（現法）是過去因緣的結果。
   - 不要僅僅追求短暫的「現法樂住」，而應關注是否在種植「善法因緣」，以確保長遠的安樂與最終的解脫。

### [段落大意]
西方比丘在回鄉安居前，經佛陀建議向舍利弗尊者請益。舍利弗教導他們如何向世人解釋佛法：核心在於調伏對五蘊（色、受、想、行、識）的欲貪。因為對五蘊的執著在面對無常變異時會產生痛苦，而斷除執著則能獲得安樂。最後，舍利弗強調善惡因緣對現世與來世的決定性影響，鼓勵修行梵行以終結痛苦。比丘們聞法後除漏解脫。
