# 雜阿含經 第 281 經

### [原文]
如是我聞：

一時，佛住王舍城迦蘭陀竹園。

時，有縈髮目揵連出家來詣佛所，共相問訊，問訊已，退坐一面。

爾時，世尊告縈髮目揵連：「汝從何來？」

縈髮目揵連白佛言：「我從彼眾多種種異道沙門、婆羅門、遮羅迦出家，集會未曾講堂聽法，從彼林來。」

佛告縈髮目揵連：「汝為何等福力故，從彼眾多種種異道沙門、婆羅門、遮羅迦出家所聽其說法？」

縈髮目揵連言：「我試聽其競勝論義福利，聽其相違反論議福利故。」

佛告目揵連：「長夜久遠，種種異道沙門、婆羅門、遮羅迦出家競勝論議，相違反論議福利，迭相破壞。」

縈髮目揵連白佛言：「瞿曇！為諸弟子說何等法福利，令彼轉為人說，不謗如來，不增不減，誠說、法說、法次法說，無有餘人能來比挍、難詰、訶責？」

佛告目連：「明、解脫、果報、福利，為人轉說者，不謗如來，不乖其理，法次法說，無有能來比挍、難詰、嫌責。」

縈髮目揵連白佛言：「瞿曇！諸弟子有法，修習多修習，令明、解脫、福利滿足者不？」

佛告縈髮目犍連：「有七覺分，修習多修習，明、解脫、福利滿足。」

縈髮目揵連白佛言：「有法修習，能令七覺分滿足不？」

佛告縈髮目揵連：「有四念處，修習多修習，能令七覺分滿足。」

縈髮目揵連白佛：「復有法修習多修習，令四念處滿足不？」

佛告縈髮目揵連：「有三妙行，修習多修習，能令四念處滿足。」

縈髮目揵連白佛言：「復有法修習多修習，令三妙行滿足不？」

佛告目揵連：「有六觸入處律儀，修習多修習，令三妙行滿足。」

縈髮目揵連白佛言：「云何六觸入處律儀，修習多修習，令三妙行滿足？」

佛告目揵連：「若眼見適意、可愛念、能長養欲樂、令人緣著之色，彼比丘見已，不喜、不讚歎、不緣、不著、不住；若眼見不適意、不可愛念、順於苦覺之色，諸比丘見已，不畏、不惡、不嫌、不恚。於彼好色，起眼見已，永不緣著；不好色，起眼見已，永不緣著；內心安住不動，善修解脫，心不懈勌。耳、鼻、舌、身、意識法亦復如是。如是於六觸入修習多修習，滿足三妙行。

「云何修三妙行，滿足四念處？多聞聖弟子於空閑處、林中、樹下，作如是學、如是思惟：『此身惡行，現世、後世必得惡報。我若行身惡行者，必當自生厭悔，他亦嫌薄，大師亦責，諸梵行者亦復以法而嫌我；惡名流布，遍於諸方，身壞命終，當墮地獄。於身惡行，見現世、後世如是果報，是故除身惡行，修身妙行，口、意惡行亦復如是。』是名修習三妙行已，得四念處清淨滿足。

「云何修四念處？得七覺分滿足？目揵連比丘！如是順身身觀住，彼順身身觀住時，攝念安住不忘。爾時，方便修習念覺分，方便修習念覺分已，得念覺分滿足，於彼心念選擇於法，覺想思量。爾時，方便修習擇法覺分，方便修習擇法覺分已，逮得擇法覺分滿足，選擇彼法，覺想思量。方便修習精進覺分，方便修習精進覺分已，逮得精進覺分滿足，勤精進已，生歡喜心。爾時，修習方便歡喜覺分，修習歡喜覺分已，逮得歡喜覺分滿足，心歡喜已，身心止息。爾時，修習猗息覺分，修習猗息覺分已，逮得猗息覺分滿足，身心息已，得三摩提。爾時，修習定覺分，修習定覺分已，定覺分滿足，謂一其心，貪憂滅息，內身行捨，方便修習捨覺分，方便修習捨覺分已，逮得捨覺分清淨滿足。受、心、法念處，亦如是說。如是修習四念處、七覺分滿足。

「云何修習七覺分？明、解脫、滿足？目揵連！若比丘修念覺分，依遠離、依離欲、依滅捨，於進趣修念覺分，逮得明、解脫、清淨滿足。乃至修習捨覺分，亦如是說，是名修習七覺分已，明、解脫、清淨滿足。如是，目揵連！法法相律，從此岸而到彼岸。」

說是法時，縈髮目揵連遠塵離垢，得法眼淨。時，縈髮目揵連見法、得法、知法、入法，度諸疑惑，不由於他，於諸法、律得無所畏。從座起，整衣服，為佛作禮，合掌白佛言：「我今寧得於正法、律出家，得具足比丘分不？」

佛告目揵連：「汝今已得於正法、律出家，具足得比丘分，得出家已，專精思惟，不放逸住，乃至成阿羅漢。」

### [白話翻譯]
**◈ 如是我聞：**
　　我是這樣聽佛陀說的：

**◈ 一時，佛住王舍城迦蘭陀竹園。**
　　在某一個時間，佛陀住在王舍城的迦蘭陀竹園。

**◈ 時，有縈髮目揵連出家來詣佛所，共相問訊，問訊已，退坐一面。**
　　那時，有一位名叫縈髮目揵連的出家修行者來到佛陀這裡，彼此問候之後，便退到一邊坐下。

**◈ 爾時，世尊告縈髮目揵連：「汝從何來？」**
　　那時，世尊問縈髮目揵連：「你是從哪裡來的？」

**◈ 縈髮目揵連白佛言：「我從彼眾多種種異道沙門、婆羅門、遮羅迦出家，集會未曾講堂聽法，從彼林來。」**
　　縈髮目揵連對佛陀恭敬地說道：「我剛從那些信仰各種不同道路的沙門、婆羅門以及遮羅迦出家者的集會處來，在那些未曾建立正式講堂的林間聽法。」

**◈ 佛告縈髮目揵連：「汝為何等福力故，從彼眾多種種異道沙門、婆羅門、遮羅迦出家所聽其說法？」**
　　佛陀問縈髮目揵連：「你是因為什麼樣的福報力量，才會去聽那些種種異道沙門、婆羅門與遮羅迦出家者所說的法？」

**◈ 縈髮目揵連言：「我試聽其競勝論義福利，聽其相違反論議福利故。」**
　　縈髮目揵連回答：「我是想嘗試聽聽他們在論辯競勝中能獲得什麼利益，以及在互相反駁的論議中能得到什麼好處。」

**◈ 佛告目揵連：「長夜久遠，種種異道沙門、婆羅門、遮羅迦出家競勝論議，相違反論議福利，迭相破壞。」**
　　佛陀告訴目揵連：「在漫長的輪迴（Saṃsāra）歲月中，各種異道沙門、婆羅門與遮羅迦出家者追求論辯的勝利，在互相反駁的論議中尋找利益，結果反而輪流地互相破壞。」

**◈ 縈髮目揵連白佛言：「瞿曇！為諸弟子說何等法福利，令彼轉為人說，不謗如來，不增不減，誠說、法說、法次法說，無有餘人能來比挍、難詰、訶責？」**
　　縈髮目揵連對佛陀恭敬地說道：「瞿曇！您為弟子們宣說什麼樣的法（Dhamma）與利益，能讓他們在轉述給他人時，不會誹謗如來（成就不變真理而來到世間的人），也不會增加或減少法義的內容，而是誠實地說法、依照法義而說、且依照法義的順序而說，使得沒有其他人能來比擬、質詢或責備？」

**◈ 佛告目連：「明、解脫、果報、福利，為人轉說者，不謗如來，不乖其理，法次法說，無有能來比挍、難詰、嫌責。」**
　　佛陀告訴目揵連：「關於明（智慧的覺知）、解脫（Vimokkha）、果報與福利的教法，若由人轉述，只要不誹謗如來，不違背其理，且依照法義順序而說，就沒有人能來比擬、質詢或嫌責。」

**◈ 縈髮目揵連白佛言：「瞿曇！諸弟子有法，修習多修習，令明、解脫、福利滿足者不？」**
　　縈髮目揵連對佛陀恭敬地說道：「瞿曇！對於弟子們來說，是否有一種法，只要多加修行（Bhāvanā），就能讓明、解脫與福利達到滿足？」

**◈ 佛告縈髮目犍連：「有七覺分，修習多修習，明、解脫、福利滿足。」**
　　佛陀告訴目揵連：「有七種覺悟的組成要素（七覺分），只要多加修行，就能讓明、解脫與福利得到滿足。」

**◈ 縈髮目揵連白佛言：「有法修習，能令七覺分滿足不？」**
　　縈髮目揵連對佛陀恭敬地說道：「是否有一種法，修行後能讓這七種覺悟要素（七覺分）得到滿足？」

**◈ 佛告縈髮目揵連：「有四念處，修習多修習，能令七覺分滿足。」**
　　佛陀告訴目揵連：「有四種正念的確立處（四念處），多加修行，能令七種覺悟要素（七覺分）得到滿足。」

**◈ 縈髮目揵連白佛：「復有法修習多修習，令四念處滿足不？」**
　　縈髮目揵連對佛陀說：「是否還有一種法，多加修行能令四種正念確立處（四念處）得到滿足？」

**◈ 佛告縈髮目揵連：「有三妙行，修習多修習，能令四念處滿足。」**
　　佛陀告訴目揵連：「有三種純淨的行為（三妙行：身、口、意的妙行），多加修行，能令四種正念確立處（四念處）得到滿足。」

**◈ 縈髮目揵連白佛言：「復有法修習多修習，令三妙行滿足不？」**
　　縈髮目揵連對佛陀恭敬地說道：「是否還有一種法，多加修行能令三種純淨行為（三妙行）得到滿足？」

**◈ 佛告目揵連：「有六觸入處律儀，修習多修習，令三妙行滿足。」**
　　佛陀告訴目揵連：「在六種感官接觸（觸）的入口處保持律儀（戒律的規範），多加修行，能令三種純淨行為（三妙行）得到滿足。」

**◈ 縈髮目揵連白佛言：「云何六觸入處律儀，修習多修習，令三妙行滿足？」**
　　縈髮目揵連對佛陀恭敬地說道：「如何修行在六種感官接觸（觸）的入口處保持律儀，才能令三種純淨行為（三妙行）得到滿足？」

**◈ 佛告目揵連：「若眼見適意、可愛念、能長養欲樂、令人緣著之色，彼比丘見已，不喜、不讚歎、不緣、不著、不住；若眼見不適意、不可愛念、順於苦覺之色，諸比丘見已，不畏、不惡、不嫌、不恚。於彼好色，起眼見已，永不緣著；不好色，起眼見已，永不緣著；內心安住不動，善修解脫，心不懈勌。耳、鼻、舌、身、意識法亦復如是。如是於六觸入修習多修習，滿足三妙行。**
　　佛陀告訴目揵連：「如果眼睛看見適意、令人喜愛、能長養欲樂且令人產生執著的色（視覺對象/物質形態），比丘在看見後，不產生喜悅、不讚歎、不追隨、不執著、不停留；如果眼睛看見不適意、不令人喜愛、且引發苦受（感受）的色（視覺對象/物質形態），比丘在看見後，不恐懼、不厭惡、不嫌棄、不憤怒。對於好色的對象，在看見後永不執著；對於不好色的對象，在看見後亦永不執著；內心安住不動，善於修行解脫（Vimokkha），心不懈怠。耳朵、鼻子、舌頭、身體以及意識（識）的接觸法也是如此。像這樣在六種感官接觸（觸）的入口處多加修行，就能滿足三種純淨行為（三妙行）。」

**◈ 「云何修三妙行，滿足四念處？多聞聖弟子於空閑處、林中、樹下，作如是學、如是思惟：『此身惡行，現世、後世必得惡報。我若行身惡行者，必當自生厭悔，他亦嫌薄，大師亦責，諸梵行者亦復以法而嫌我；惡名流布，遍於諸方，身壞命終，當墮地獄。於身惡行，見現世、後世如是果報，是故除身惡行，修身妙行，口、意惡行亦復如是。』是名修習三妙行已，得四念處清淨滿足。**
　　「如何修行三種純淨行為（三妙行）來滿足四種正念確立處（四念處）？博學的聖弟子在空閑處、林中或樹下，進行這樣的學習與思惟：『身體的惡行，在現世與後世必定會得到惡報（業報）。如果我做出身體的惡行，我必然會自覺厭悔，他人也會嫌棄我，老師也會責備我，其他修行梵行的人也會依照法義而嫌棄我；惡名將傳遍各方，當身體毀壞、生命終結時，將會墮入地獄。對於身體的惡行，看到了現世與後世如此的果報，因此應該除掉身體的惡行，修行身體的妙行；口業與意業（心的造作）的惡行也是如此。』這就叫做修習三種純淨行為（三妙行），進而使四種正念確立處（四念處）得到清淨滿足。」

**◈ 「云何修四念處？得七覺分滿足？目揵連比丘！如是順身身觀住，彼順身身觀住時，攝念安住不忘。爾時，方便修習念覺分，方便修習念覺分已，得念覺分滿足，於彼心念選擇於法，覺想思量。爾時，方便修習擇法覺分，方便修習擇法覺分已，逮得擇法覺分滿足，選擇彼法，覺想思量。方便修習精進覺分，方便修習精進覺分已，逮得精進覺分滿足，勤精進已，生歡喜心。爾時，修習方便歡喜覺分，修習歡喜覺分已，逮得歡喜覺分滿足，心歡喜已，身心止息。爾時，修習猗息覺分，修習猗息覺分已，逮得猗息覺分滿足，身心息已，得三摩提。爾時，修習定覺分，修習定覺分已，定覺分滿足，謂一其心，貪憂滅息，內身行捨，方便修習捨覺分，方便修習捨覺分已，逮得捨覺分清淨滿足。受、心、法念處，亦如是說。如是修習四念處、七覺分滿足。**
　　「如何修行四種正念確立處（四念處）來滿足七種覺悟要素（七覺分）？目揵連比丘！當如實地對身體進行身觀（觀察身體）並安住其中，在身觀安住時，將正念攝持安住而不忘失。那時，透過方便方法修習念覺分（正念），修習後使念覺分滿足，心念便能選擇法義，進行覺悟的思考與思量。那時，透過方便方法修習擇法覺分（審視法義），修習後使擇法覺分滿足，進而能選擇法義，進行覺悟的思考與思量。透過方便方法修習精進覺分（勤奮），修習後使精進覺分滿足，在勤奮精進後，會生起歡喜心。那時，修習方便的歡喜覺分（法喜），修習後使歡喜覺分滿足，心歡喜後，身心便止息平靜。那時，修習猗息覺分（身心安適），修習後使猗息覺分滿足，身心止息後，進入三摩提（定）。那時，修習定覺分（專注），修習後使定覺分滿足，使心一境專注，貪欲與憂愁滅息，內在身心行捨（中立），進而方便地修習捨覺分（平等心），修習後使捨覺分得到清淨滿足。對於受（感受）、心（意識狀態）、法（現象）的念處，也是如此說明。像這樣修習四種正念確立處（四念處），就能使七種覺悟要素（七覺分）滿足。」

**◈ 「云何修習七覺分？明、解脫、滿足？目揵連！若比丘修念覺分，依遠離、依離欲、依滅捨，於進趣修念覺分，逮得明、解脫、清淨滿足。乃至修習捨覺分，亦如是說，是名修習七覺分已，明、解脫、清淨滿足。如是，目揵連！法法相律，從此岸而到彼岸。」**
　　「如何修習七種覺悟要素（七覺分）來滿足明與解脫（Vimokkha）？目揵連！如果比丘修習念覺分，依據遠離（世俗）、依據離欲、依據滅除執著的捨心，在進趣的過程中修習念覺分，就能獲得明、解脫與清淨的滿足。直到修習捨覺分，也是如此說明。這就叫做修習七種覺悟要素（七覺分），進而使明、解脫與清淨得到滿足。目揵連，這就是依照法義的相貌與律則，從此岸（生死輪迴）到達彼岸（涅槃）。」

**◈ 說是法時，縈髮目揵連遠塵離垢，得法眼淨。時，縈髮目揵連見法、得法、知法、入法，度諸疑惑，不由於他，於諸法、律得無所畏。從座起，整衣服，為佛作禮，合掌白佛言：「我今寧得於正法、律出家，得具足比丘分不？」**
　　佛陀在說這段法義時，縈髮目揵連遠離了煩惱的塵垢，獲得了清淨的法眼。那時，縈髮目揵連見到了法、得到了法、認知了法並進入了法，超越了所有疑惑，不再依賴他人，對於所有的法與律則不再有恐懼。他從座位上起立，整理衣服，向佛陀行禮，合掌對佛陀恭敬地說道：「我現在能否在正法與律則中出家，獲得具足的比丘身分？」

**◈ 佛告目揵連：「汝今已得於正法、律出家，具足得比丘分，得出家已，專精思惟，不放逸住，乃至成阿羅漢。」**
　　佛陀告訴目揵連：「你現在已經在正法與律則中出家，具足了比丘的身分。出家之後，請專精於思惟，不放逸地生活，直到成就阿羅漢（Arahant）。」

### [詞語註解]
1. **六觸入處律儀 (Six Sense Restraints)**：指在六根（眼、耳、鼻、舌、身、意）與六境（色、聲、香、味、觸、法）接觸（觸）的瞬間，保持覺知且不產生貪愛或厭惡的反應，從而防止煩惱的生起。
2. **三妙行 (Three Pure Actions)**：指在身體、言語、意念三個層面上，透過對惡業果報的思惟，而轉化為純淨、不傷害他人的正向行為。
3. **四念處 (Satipaṭṭhāna)**：正念的四種確立對象，分別為：身（物質身體）、受（感受）、心（意識狀態）、法（心理現象/真理）。
4. **七覺分 (Satta Bojjhaṅga)**：導向覺悟的七個心理要素，包含：念（正念）、擇法（審視法義）、精進（勤奮）、歡喜（法喜）、猗息（身心安適）、定（專注）、捨（平等心）。
5. **法眼淨 (Dharma-eye)**：指修行者突破無明，能如實觀察世間萬法之緣起與無常的智慧狀態。
6. **不放逸 (Appamāda)**：指時刻保持警覺，不讓心在貪、嗔、癡中遊蕩，持續地在正法上精進。

### [現代實作指南]
本經文提供了一個由淺入深的「修行階梯」，可將其轉化為現代生活中的心理實踐步驟：

1. **第一階段：感官守門（六觸入處律儀）**
   - **實作**：在面對社交媒體的資訊（色）、他人的批評（聲）或不適的環境（觸）時，練習在「反應」之前創造一個空隙。
   - **轉念**：告訴自己：「我現在看見/聽見了這個對象，但我不需要立刻對它產生『喜歡』或『討厭』的標籤。」

2. **第二階段：因果反思（三妙行）**
   - **實作**：在準備做出衝動行為（如憤怒地回覆訊息）前，進行短暫的「果報模擬」。
   - **轉念**：思考「如果我現在採取這個惡行，會帶來什麼後果？（如：關係破裂、內心不安、名聲受損）」。透過對負面結果的預見，自然產生對惡行的厭離心，進而選擇更溫和、純淨的處理方式。

3. **第三階段：正念觀察（四念處 ➔ 七覺分）**
   - **實作**：將注意力從「對象」移回「觀察者」。
   - **路徑**：
     - **觀察身體** → 發現呼吸的律動（念）。
     - **分析狀態** → 辨識目前的壓力是屬於「受」還是「想」（擇法）。
     - **持續維持** → 即使分心也溫柔地將心帶回（精進）。
     - **體驗平靜** → 感受當下不被情緒牽著走的輕鬆感（歡喜 → 猗息 → 定 → 捨）。
