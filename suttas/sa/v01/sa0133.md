# 雜阿含經 第 133 經

### [原文]
如是我聞：

一時，佛住舍衛國祇樹給孤獨園。

爾時，世尊告諸比丘：「何所有故，何所起？何所繫著，何所見我？令眾生無明所蓋，愛繫其首，長道驅馳，生死輪迴，生死流轉，不去本際？」

諸比丘白佛言：「世尊是法根、法依。善哉！世尊！唯願哀愍，廣說其義，諸比丘聞已，當受奉行。」

佛告比丘：「諦聽，善思，當為汝說。諸比丘！色有故，色事起，色繫著，色見我，令眾生無明所蓋，愛繫其首，長道驅馳，生死輪迴，生死流轉。受、想、行、識亦復如是。諸比丘！色為常耶？為非常耶？」

答曰：「無常。世尊！」

復問：「若無常者，是苦耶？」

答曰：「是苦。世尊！」

「如是，比丘！若無常者是苦，是苦有故，是事起、繫著、見我，令眾生無明所蓋，愛繫其頭，長道驅馳，生死輪迴，生死流轉。受、想、行、識亦復如是。是故，諸比丘！諸所有色，若過去、若未來、若現在，若內、若外、若麤、若細，若好、若醜，若遠、若近，彼一切非我、非異我、不相在，是名正慧。受、想、行、識亦復如是。

「如是見、聞、覺、識，求得隨憶、隨覺、隨觀，彼一切非我、非異我、不相在，是名正慧。

「若有見言有我、有世間、有此世、常、恒、不變易法，彼一切非我、非異我、不相在，是名正慧。

「若復有見非此我、非此我所、非當來我、非當來我所，彼一切非我、非異我、不相在，是名正慧。

「若多聞聖弟子於此六見處觀察非我、非我所，如是觀者，於佛所狐疑斷，於法、於僧狐疑斷。是名，比丘！多聞聖弟子不復堪任作身、口、意業，趣三惡道；正使放逸，聖弟子決定向三菩提，七有天人往來，作苦邊。」

佛說此經已，諸比丘聞佛所說，歡喜奉行。

### [白話翻譯]
**◈ 如是我聞：**
　　我是這樣聽佛陀說的：

**◈ 一時，佛住舍衛國祇樹給孤獨園。**
　　在某一個時間，佛陀住在舍衛國的祇樹給孤獨園。

**◈ 爾時，世尊告諸比丘：「何所有故，何所起？何所繫著，何所見我？令眾生無明所蓋，愛繫其首，長道驅馳，生死輪迴，生死流轉，不去本際？」**
　　那時，世尊告訴在場的眾位比丘說：「是因為有什麼存在，才會導致種種現象興起？是因為什麼而被繫縛？又是因為什麼而產生『我』的錯覺？導致眾生被無明（對真理的無知）所遮蔽，被愛（貪愛）繫住頭頂，在漫長的道路上奔波驅馳，陷入生死輪迴（Saṃsāra）的循環，在生死中流轉，無法回到解脫的本源之處？」

**◈ 諸比丘白佛言：「世尊是法根、法依。善哉！世尊！唯願哀愍，廣說其義，諸比丘聞已，當受奉行。」**
　　比丘們對佛陀恭敬地說道：「世尊您是正法的根源與依據。好極了！世尊！唯願您慈悲憐憫，為我們詳細解說其中的義理，我們聽聞之後，定會虔誠地接受並依照教導去實踐。」

**◈ 佛告比丘：「諦聽，善思，當為汝說。諸比丘！色有故，色事起，色繫著，色見我，令眾生無明所蓋，愛繫其首，長道驅馳，生死輪迴，生死流轉。受、想、行、識亦復如是。諸比丘！色為常耶？為非常耶？」**
　　佛陀告訴比丘：「仔細聽，好好思考，我現在為你們解說。比丘們！因為有色（物質身體）存在，所以與物質相關的事物才會興起，人會被物質身體所繫縛，並將物質身體誤認為『我』，這導致眾生被無明（對真理的無知）所遮蔽，被愛（貪愛）繫住頭頂，在漫長的道路上奔波驅馳，陷入生死輪迴（Saṃsāra）的循環，在生死中流轉。受（感受）、想（想像與認知）、行（心的造作）、識（意識）這四種心法也是同樣的情況。比丘們！色（物質身體）是恆常不變的嗎？還是非恆常的？」

**◈ 答曰：「無常。世尊！」**
　　比丘們回答：「是無常的，世尊！」

**◈ 復問：「若無常者，是苦耶？」**
　　佛陀再次詢問：「如果它是無常的，那它是否就是苦（Dukkha）？」

**◈ 答曰：「是苦。世尊！」**
　　比丘們回答：「是苦的，世尊！」

**◈ 「如是，比丘！若無常者是苦，是苦有故，是事起、繫著、見我，令眾生無明所蓋，愛繫其頭，長道驅馳，生死輪迴，生死流轉。受、想、行、識亦復如是。**
　　「確實如此，比丘！既然無常的東西就是苦，而因為這種苦的性質存在，才導致相關事物的興起、產生繫縛、並讓人將其視為『我』，進而令眾生被無明（對真理的無知）所遮蔽，被愛（貪愛）繫住頭頂，在漫長的道路上奔波驅馳，陷入生死輪迴（Saṃsāra）的循環，在生死中流轉。受（感受）、想（想像與認知）、行（心的造作）、識（意識）也是同樣的情況。

**◈ 是故，諸比丘！諸所有色，若過去、若未來、若現在，若內、若外、若麤、若細，若好、若醜，若遠、若近，彼一切非我、非異我、不相在，是名正慧。受、想、行、識亦復如是。**
　　因此，比丘們！所有屬於色（物質身體）的現象，無論是過去、未來或現在，無論是內在或外在，無論是粗糙或微細，無論是好看或醜陋，無論是遙遠或靠近，這一切都不是『我』，也不是『與我不同的另一個我』，更不是『獨立存在於兩者之外的實體』，這樣認知才叫做正慧（正確的智慧）。受（感受）、想（想像與認知）、行（心的造作）、識（意識）也是同樣的情況。

**◈ 「如是見、聞、覺、識，求得隨憶、隨覺、隨觀，彼一切非我、非異我、不相在，是名正慧。**
　　「同樣地，對於視覺、聽覺、覺知與意識，無論是透過記憶回想、當下覺察或深入觀察所得到的認知，這一切都不是『我』，也不是『與我不同的另一個我』，更不是『獨立存在於兩者之外的實體』，這才叫做正慧（正確的智慧）。

**◈ 「若有見言有我、有世間、有此世、常、恒、不變易法，彼一切非我、非異我、不相在，是名正慧。**
　　「如果有人持有某種見解，認為存在一個恆久的『我』，或者認為存在一個永恆的世間、這個世界，或是某種恆常不變的法，若能體悟到這一切見解本身都不是『我』，也不是『與我不同的另一個我』，更不是『獨立存在於兩者之外的實體』，這才叫做正慧（正確的智慧）。

**◈ 「若復有見非此我、非此我所、非當來我、非當來我所，彼一切非我、非異我、不相在，是名正慧。**
　　「即便有人持有另一種見解，認為『這不是我』、『這不是我所擁有的』、『這不是未來的我』或『這不是未來我所擁有的』，若能進一步體悟到這種『否定』的見解本身，同樣也不是『我』，也不是『與我不同的另一個我』，更不是『獨立存在於兩者之外的實體』，這才叫做正慧（正確的智慧）。

**◈ 「若多聞聖弟子於此六見處觀察非我、非我所，如是觀者，於佛所狐疑斷，於法、於僧狐疑斷。**
　　「如果一位博學的聖弟子在上述這六種見解處（對五蘊的執著與對非我的否定）中，觀察到這一切都不是『我』，也不是『我所擁有的』，如此觀察的人，對於佛陀的懷疑會被消除，對於法（Dhamma）與僧團的懷疑也會被消除。

**◈ 是名，比丘！多聞聖弟子不復堪任作身、口、意業，趣三惡道；正使放逸，聖弟子決定向三菩提，七有天人往來，作苦邊。」**
　　比丘們！這就叫做博學的聖弟子不再造就會導致墮入三惡道（地獄、餓鬼、畜生）的身、口、意業；他能正當地精進（不放逸），決定地邁向最高、最圓滿的智慧與覺悟（阿耨多羅三藐三菩提），即便在七種存在層級（七有）的天人之間往來，最終也會讓痛苦到達邊際而終結。」

**◈ 佛說此經已，諸比丘聞佛所說，歡喜奉行。**
　　佛陀講完這部經後，眾比丘聽聞佛陀所說的教法，心生法喜並依照教導去實踐。

### [詞語註解]
1. **五蘊 (Pañca-khandha)**：構成生命個體的五種要素，包含色（物質）、受（感受）、想（認知）、行（意志造作）、識（意識）。
2. **無明 (Avijjā)**：對四聖諦及緣起真理的無知，是導致輪迴的根本原因。
3. **三惡道 (Tiracchāna-yoga/etc.)**：指地獄、餓鬼、畜生三種痛苦的生存狀態。
4. **七有 (Satta-bhava)**：指欲界、色界、無色界中七種不同的存在層級。
5. **非我、非異我、不相在 (Na attā, na aññattā, na ca ubhayattā)**：一種徹底的否定分析法。首先否定它是「我」，再否定它是「與我不同的他者」，最後否定它是一個「獨立存在的實體」，旨在破除一切對實體自我的執著。

### [現代實作指南]
本經文的核心在於透過「分析法」來解構對「我」的執著。在現代生活中，我們可以將此轉化為以下實踐步驟：

1. **標記五蘊 (Labeling)**：
   當強烈的情緒或壓力襲來時，不要說「我很痛苦」，而是在心中將其拆解：
   ➔ 身體感覺到緊繃 ➔ 這是「色（物質身體）」的現象。
   ➔ 感覺到不舒服、厭惡 ➔ 這是「受（感受）」的現象。
   ➔ 大腦在想「為什麼這件事發生在我身上」 ➔ 這是「想（認知）」的現象。
   ➔ 心中產生反抗或憤怒的衝動 ➔ 這是「行（心的造作）」的現象。
   ➔ 意識到上述所有過程 ➔ 這是「識（意識）」的現象。

2. **應用「三不」分析法 (The Triple Negation)**：
   針對上述標記的現象，進行理智詢問：
   ➔ **非我**：這個憤怒的感受是恆常的嗎？它會消失，所以它不是一個永恆的「我」。
   ➔ **非異我**：這個感受是我可以完全控制的外部物件嗎？它與我的心緊密相連，所以它也不是一個獨立於我之外的「他者」。
   ➔ **不相在**：如果它既不是我，也不是他者，那它是否是一個獨立存在的實體？不，它只是因緣（壓力 ➔ 認知 ➔ 反應）而生的暫時現象。

3. **轉念技巧**：
   將「我的失敗」轉化為「一次失敗的經驗（行/想）正在發生」。當你將「我」從現象中抽離，你就不再是被繫縛的囚徒，而是一個觀察現象的觀測者。這能有效降低情緒的衝擊力，將「苦」轉化為「對苦的觀察」。

### [段落大意]
佛陀透過對話，揭示眾生陷入生死輪迴的根源在於將「五蘊」（色、受、想、行、識）誤認為「我」。由於五蘊本質無常且屬苦，對其產生的貪愛與無明導致了繫縛。佛陀教導正慧即是體悟五蘊及所有見解皆「非我、非異我、不相在」。能如此觀察的聖弟子將能消除疑慮，停止造作惡業，最終終結痛苦，達成最高覺悟。
