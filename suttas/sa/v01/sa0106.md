# 雜阿含經 第 106 經

### [原文]
如是我聞：

一時，佛住王舍城迦蘭陀竹園。爾時，有比丘名阿㝹羅度，住耆闍崛山。

時，有眾多外道出家往詣阿㝹羅度所，共相問訊。共相問訊已，於一面住，白阿㝹羅度言：「欲有所問，寧有閑暇為解釋不？」

阿㝹羅度語諸外道言：「隨所欲問，知者當答。」

諸外道復問：「云何，尊者！如來死後為有耶？」

阿㝹羅度言：「如世尊說，此是無記。」

又問：「如來死後為無耶？」

阿㝹羅度言：「如世尊說，此亦無記。」

又問：「如來死後有無耶？非有非無耶？」

阿㝹羅度言：「如世尊說，此亦無記。」

復問阿㝹羅度言：「云何，尊者！『如來死後有耶？』說言：『無記』；『死後無耶？』說言：『無記』；『死後有無耶？』『非有非無耶？』說言：『無記』？云何，尊者！沙門瞿曇為不知不見耶？」

阿㝹羅度言：「世尊非不知、非不見。」

時，諸外道於阿㝹羅度所說，心不喜悅，呵罵已，從座起去。

時，阿㝹羅度知諸外道去已，往詣佛所，稽首佛足，於一面住，以諸外道所問，向佛廣說，白佛言：「世尊！彼如是問，我如是答，為順諸法說耶？得無謗世尊耶？為順法耶？為違法耶？無令他來難詰，墮呵責處耶？」

佛告阿㝹羅度言：「我今問汝，隨所問答。阿㝹羅度！色為常耶？為無常耶？」

答言：「無常。」

「受、想、行、識，為常、無常耶？」

答言：「無常。世尊！」

如焰摩迦契經廣說，乃至「識是如來耶？」

答曰：「不也。」

佛告阿㝹羅度：「作如是說者，隨順諸說，不謗如來，非為越次，如如來說，諸次法說，無有能來難詰訶責者。所以者何？我於色如實知，色集、色滅、色滅道跡如實知。阿㝹羅度！若捨如來所作，無知無見說者，此非等說。」

佛說此經已，阿㝹羅度聞佛所說，歡喜奉行。

### [白話翻譯]
**◈ 如是我聞：**
　　我是這樣聽佛陀說的：

**◈ 一時，佛住王舍城迦蘭陀竹園。爾時，有比丘名阿㝹羅度，住耆闍崛山。**
　　在某一個時間，佛陀住在王舍城的迦蘭陀竹園。那時，有一位名叫阿㝹羅度的比丘，住在耆闍崛山。

**◈ 時，有眾多外道出家往詣阿㝹羅度所，共相問訊。**
　　那時，有許多出家的外道前往阿㝹羅度比丘的地方，彼此問候。

**◈ 共相問訊已，於一面住，白阿㝹羅度言：「欲有所問，寧有閑暇為解釋不？」**
　　問候完畢後，他們站在一旁，對阿㝹羅度比丘說：「我們想要請問一些問題，請問您現在是否有空為我們解答？」

**◈ 阿㝹羅度語諸外道言：「隨所欲問，知者當答。」**
　　阿㝹羅度對那些外道說：「請隨意提問，只要我知道的都會回答。」

**◈ 諸外道復問：「云何？尊者！如來死後為有耶？」**
　　外道們接著問：「尊者，請問如來在死後是否還存在？」

**◈ 阿㝹羅度言：「如世尊說，此是無記。」**
　　阿㝹羅度回答：「正如世尊所說，這個問題屬於無記（不予回答，因為對解脫無益）。」

**◈ 又問：「如來死後為無耶？」**
　　他們又問：「那麼如來在死後是否不存在？」

**◈ 阿㝹羅度言：「如世尊說，此亦無記。」**
　　阿㝹羅度回答：「正如世尊所說，這個問題同樣屬於無記。」

**◈ 又問：「如來死後有無耶？非有非無耶？」**
　　他們再次問：「如來在死後是存在還是不存在？或者既非存在也非不存在？」

**◈ 阿㝹羅度言：「如世尊說，此亦無記。」**
　　阿㝹羅度回答：「正如世尊所說，這個問題依然屬於無記。」

**◈ 復問阿㝹羅度言：「云何？尊者！如來死後有耶？說言無記。死後無耶？說言無記。死後有無耶？非有非無耶？說言無記。云何？尊者！沙門瞿曇為不知、不見耶？」**
　　他們又對阿㝹羅度比丘說：「尊者，關於如來死後是否存在，您說無記；死後是否不存在，您也說無記；死後是存在、不存在，或是非有非無，您都說無記。請問尊者，難道沙門瞿曇（佛陀）是因為不知道、看不透才這樣回答的嗎？」

**◈ 阿㝹羅度言：「世尊非不知、非不見。」**
　　阿㝹羅度回答：「世尊並非不知道，也不是看不透。」

**◈ 時，諸外道於阿㝹羅度所說，心不喜悅，呵罵已，從座起去。**
　　那時，那些外道對阿㝹羅度的回答感到不滿，在呵斥辱罵之後，便從座位上起身離開了。

**◈ 時，阿㝹羅度知諸外道去已，往詣佛所，稽首佛足，於一面住，以諸外道所問，向佛廣說，白佛言：「世尊！彼如是問，我如是答，為順諸法說耶？得無謗世尊耶？為順法耶？為違法耶？無令他來難詰，墮呵責處耶？」**
　　那時，阿㝹羅度知道外道們已經離開，便前往佛陀那裡，頂禮佛足，站在一旁，將外道們所問的問題詳細地告訴佛陀，並對佛陀恭敬地說道：「世尊！他們這樣問，而我這樣回答，是否符合法（真理）的教導？是否沒有誹謗世尊？是順應法還是違背法？這樣回答是否能避免讓他人在此詰問我，而使我陷入被呵責的境地？」

**◈ 佛告阿㝹羅度言：「我今問汝，隨所問答。阿㝹羅度！色為常耶？為無常耶？」**
　　佛陀告訴阿㝹羅度：「我現在問你，請隨問隨答。阿㝹羅度！色（物質身體）是恆常的，還是無常（變易不恆）的？」

**◈ 答言：「無常。」**
　　他回答：「是無常的。」

**◈ 「受、想、行、識，為常、無常耶？」**
　　佛陀問：「受（感受）、想（想像與認知）、行（心的造作）、識（意識），是恆常的還是無常的？」

**◈ 答言：「無常。世尊！」**
　　他回答：「世尊，它們都是無常的！」

**◈ 如焰摩迦契經廣說，乃至「識是如來耶？」**
　　（此處省略如《焰摩迦契經》中詳細的問答過程），直到問到：「識（意識）就是如來嗎？」

**◈ 答曰：「不也。」**
　　他回答：「不是。」

**◈ 佛告阿㝹羅度：「作如是說者，隨順諸說，不謗如來，非為越次，如如來說，諸次法說，無有能來難詰訶責者。**
　　佛陀告訴阿㝹羅度：「你這樣回答，是隨順於佛陀對那些不予回答之問題（無記）的處理方式，沒有誹謗如來，也沒有越權發言；你的回答完全符合如來的教導，這種循序漸進的法說，不會有人能以此來詰問或呵責你。

**◈ 所以者何？我於色如實知，色集、色滅、色滅道跡如實知。**
　　為什麼呢？因為我對色（物質身體）有如實的覺知，對於色（物質身體）如何因緣而生（集）、如何消亡（滅），以及導致色（物質身體）消亡的道路（滅道跡）都有如實的覺知。

**◈ 阿㝹羅度！若捨如來所作，無知無見說者，此非等說。」**
　　阿㝹羅度！如果捨棄如來所建立的教法，而去說一些毫無知見、毫無根據的話，那才是不對等的錯誤說法。」

**◈ 佛說此經已，阿㝹羅度聞佛所說，歡喜奉行。**
　　佛陀講完這部經後，阿㝹羅度聽聞佛陀所說的教法，心生法喜並依照教導去實踐。

### [詞語註解]
1. **無記 (Avyākata)**：指佛陀對於某些哲學性、形而上學的問題（如世界是否有邊界、如來死後有無等）不給予肯定的回答。這是因為這些問題本身建立在「自我」存在的錯誤前提下，且對斷除煩惱、解脫涅槃無益。
2. **阿㝹羅度 (Anurādha)**：比丘名，亦譯作阿㝹樓陀（不同於佛陀堂弟天眼第一的阿那律）。
3. **如實知 (Yathābhūtaṃ pajānāti)**：指依照事物本來的面目去觀察與徹知，而不加入主觀的想像或執著。在本經中特指對四聖諦（苦、集、滅、道）的現量認知。
4. **焰摩迦契經 (Yamaka Sutta)**：指阿含經中另一篇著名的經文，探討「如來死後有無」的邪見，強調不應將五陰（色受想行識）誤認為如來。

### [現代實作指南]
本經文揭示了一個重要的心理實踐技巧：**「區分有效問題與無效問題」**。

1. **識別「無記」陷阱**：
   在生活中，我們常陷入對「不可知」或「對當下無益」的糾結中（例如：如果我死後不存在怎麼辦？如果對方內心真正想的是什麼？）。這些問題就像經文中的「如來死後有無」，無論答案是什麼，都無法解決當下的痛苦。
   ➔ **實作**：當你發現自己陷入循環思考且無法得出結論時，對自己說：「這是一個『無記』問題，對我目前的解脫沒有幫助。」

2. **將焦點轉向「五蘊」的觀察**：
   佛陀將討論從「死後狀態」轉向「色、受、想、行、識」的無常。這是一種將「形而上學的幻想」轉化為「經驗科學的觀察」的方法。
   ➔ **實作**：與其思考「我」在未來會變成什麼，不如觀察當下的「我」：
   - **色**：觀察身體的緊繃或疼痛（物質身體的無常）。
   - **受**：觀察此刻的情緒是苦、樂還是捨（感受的無常）。
   - **想**：觀察腦中浮現的標籤與定義（認知的無常）。
   - **行**：觀察內心升起的衝動或反應（造作的無常）。
   - **識**：觀察意識如何在不同對象間跳轉（意識的無常）。

3. **以「如實知」取代「推論」**：
   外道試圖用邏輯推論（有、無、非有非無）來定義真理，而佛陀強調「如實知」（直接觀察事實）。
   ➔ **實作**：停止對生活的「定義」與「推論」，開始對生活的「觀察」。不要問「為什麼這件事會發生」，而要問「現在發生了什麼，它的特質是否在變動」。

### [段落大意]
外道詢問比丘阿[少/兔]羅度關於佛陀死後是否存在之問題，比丘依佛陀教導回答為「無記」。外道不滿而離去。比丘隨後向佛陀確認回答是否正確，佛陀透過引導比丘體悟五蘊（色受想行識）的無常，證明唯有如實觀察現象的生滅與滅道，才是正確的法說，而非陷入無益的形而上學推論。
